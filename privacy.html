Privacy Policy

Last updated: 2026-11-04

Openclaw is a private, single-user personal assistant operated by an individual (Shahar) for his own use. It is not available to the public. This policy explains how it handles Google user data.

Data accessed

With the owner's consent through Google's OAuth screen, Openclaw accesses the owner's own Google data through the Gmail API and the Google Calendar API: email messages and metadata, and calendar events. No other person's Google data is accessed.

How the data is used

The data is used only to provide the owner's personal assistant features: finding and organizing the owner's email, and reading calendar events to send the owner reminders and trip briefings. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and sharing

OAuth credentials are stored encrypted on the owner's own server. Google user data is processed on the owner's own server and is not sold, shared with third parties, used for advertising, or used to train generalized AI models. Content may be passed to an AI model provider only transiently, only as needed to carry out a task the owner requested, and only for the owner's benefit.

Retention and deletion

Data is retained only as long as needed to perform the owner's requested tasks. The owner can revoke access at any time at myaccount.google.com/permissions, and can delete stored credentials from the server.
